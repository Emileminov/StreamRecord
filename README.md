# StreamRecord

Нативное macOS-приложение (AppKit + AVFoundation, без SwiftUI и без Xcode-проекта) для записи
видео с USB-веб-камеры в режиме **USB Streaming**.

## Возможности

- Выпадающий список всех видео-устройств (`AVCaptureDevice.devices(for: .video)`)
- Живое превью с выбранной камеры (`AVCaptureVideoPreviewLayer`)
- Круглая красная кнопка записи, наложена на нижний край видео; таймер слева
- Кольцевой индикатор уровня звука вокруг кнопки — виден всегда, заполняется
  снизу по часовой (зелёный → жёлтый → красный)
- Сетка третей на превью — галочка «Сетка» справа от кнопки записи (светлые
  полупрозрачные линии; только на превью, в записанное видео не попадает;
  состояние запоминается)
- Переключатель формата **Горизонтально 16:9 / Вертикально 9:16**
- Кнопка «Выбрать папку» (по умолчанию `~/Desktop/StreamRecord`, создаётся автоматически; выбранная папка запоминается между запусками)
- Строка статуса с именем последнего сохранённого файла
- Запись в нативный `.mov` (`AVCaptureMovieFileOutput`), без перекодирования
  в горизонтали
- Имя файла — таймштамп: `streamrecord-2026-09-08-153000.mov`
- Смена камеры / микрофона / формата подхватывается на лету

## Звук

Поведение зависит от галочки **«+.wav»**:

**«+.wav» выключена** — выбранный в списке «Звук» микрофон пишется дорожкой
**внутрь `.mov`** (`AVCaptureSession`, синхронно). Отдельного файла нет.

**«+.wav» включена (по умолчанию)** — два разных источника:
- в `.mov` идёт **звук камеры** (аудиоустройство подбирается по имени камеры);
- микрофон, выбранный в списке «Звук», пишется в **отдельный файл**
  `streamrecord-<таймштамп>-audio.wav` через `AVAudioEngine`, наведённый на это
  конкретное устройство (Core Audio device ID, не «вход по умолчанию»). Отдельная
  подсистема — на звук в `.mov` не влияет. 16-бит PCM; если формат `.wav` не
  примет — `.caf`.

`.wav` начинает писаться в момент реального старта `.mov` (`didStartRecordingTo`),
движок к этому моменту уже прогрет — поэтому старты совпадают. Кольцо-индикатор
показывает уровень микрофона из списка (из тапа движка).

Ограничения: два аудиоустройства тактируются своими клоками — на длинных дублях
(10+ мин) `.wav` может чуть уезжать. Если камера не нашлась по имени — `.mov`
будет без звука (скажи имена устройств, поправлю матчинг). Одно и то же устройство
в `.mov` и `.wav` — возможны артефакты, ставь разные.

## Про вертикальный формат

Sony ZV-E10 в USB-стриминге всегда отдаёт **горизонтальный** кадр, поэтому режим
«Вертикально 9:16» рассчитан на то, что камера физически повёрнута на бок
(портретное крепление на штативе).

- Если драйвер камеры умеет поворот на лету — превью и файл сразу вертикальные,
  без перекодирования.
- Если не умеет (частый случай с UVC) — приложение пишет как есть, а после
  остановки **доворачивает файл на 90°** через `AVAssetExportSession`
  (короткий экспорт, файл получает суффикс `-vertical.mov`). В статусе видно
  «Поворачиваю видео в вертикаль…».

Нужен поворот в другую сторону — скажи, поменяю знак в `rotateToVertical`.

## Что нужно поставить

Xcode Command Line Tools (компилятор `swiftc`):

```bash
xcode-select --install
```

## Сборка и запуск

```bash
chmod +x build.sh && ./build.sh
```

Скрипт скомпилирует `Sources/main.swift`, соберёт `build/StreamRecord.app`,
подпишет его ad-hoc подписью и откроет папку `build`. Запускать — двойным кликом
по `StreamRecord.app`.

## Если macOS не даёт открыть приложение

`build.sh` сам снимает метку карантина (`xattr -dr com.apple.quarantine`) и
запускает приложение через `open` — после этого двойной клик работает без
«Правый клик → Открыть».

Если всё же появился диалог «не удаётся проверить разработчика» (например,
приложение скопировали на другой Mac):

- **Правый клик по `StreamRecord.app` → «Открыть»**, затем ещё раз «Открыть».
- Либо один раз вручную: `xattr -dr com.apple.quarantine build/StreamRecord.app`

Для быстрых прогонов без пересборки `.app` можно запускать бинарник напрямую —
Gatekeeper его вообще не проверяет:

```bash
build/StreamRecord.app/Contents/MacOS/StreamRecord
```

## Если после пересборки пропал доступ к камере

При каждой пересборке подпись меняется, и macOS считает это «новым» приложением —
разрешение на камеру/микрофон сбрасывается.

1. Открыть **Системные настройки → Конфиденциальность и безопасность**.
2. Разделы **Камера** и **Микрофон** — включить галочку напротив `StreamRecord`
   (или удалить старую запись и заново разрешить при следующем запросе).
3. Перезапустить приложение.

## Подсказки по USB-камерам

- Некоторые камеры (например Sony ZV-E10) требуют включения режима **USB Streaming** в меню камеры.
- После подключения кабелем камера появится в выпадающем списке как отдельное
  видео-устройство. Выберите её — появится превью.
